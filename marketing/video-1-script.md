# 视频号首条营销视频 — 脚本 + 分镜 + 拍摄计划

> **目标平台**: 视频号 (WeChat Channels)  
> **目标受众**: 中国家长 + 初高中学生  
> **时长**: 45秒 (黄金完播区间)  
> **发布时间**: 19:00–22:00 (家长刷手机高峰)  
> **语言**: 全中文 (口语化、带情绪)

## 一、视频脚本 (45秒)

### 开场钩子 (0–3秒) — 必须留住人

**画面**: 镜头快速扫过堆满试卷和笔记本的书桌，手一推，纸张散落。
**字幕**: 笔记堆成山，重点找不到？
**配音**: *"笔记记了三大本，考试还是找不到重点？"*
**音效**: 纸张哗啦声 + 轻微焦虑感背景音

---

### 问题放大 (3–8秒)

**画面**: 手机备忘录里密密麻麻的文字，手指疯狂滑动，表情烦躁。
**字幕**: 背了忘，忘了背，循环焦虑
**配音**: *"背了忘，忘了背，孩子焦虑，家长更焦虑。"*
**音效**: 时钟滴答声 (加速)

---

### 解决方案亮相 (8–12秒)

**画面**: 手机对准一张写满公式的纸，「咔嚓」一拍。屏幕闪过 OCR 扫描动画 (文字被高亮框选)。
**字幕**: 拍一下，AI 自动整理
**配音**: *"现在，拍一下——"*
**音效**: 清脆快门声 + 科技感的 "滴" 声

---

### 魔法时刻 (12–25秒) — 核心产品演示

**画面**: 手机屏幕录屏 (竖屏 9:16)
- 上传 PDF/图片 → 进度条飞跑
- OCR 提取文字 → 文字块飞入
- AI 分析 → 节点自动连线，知识图谱「唰」地展开
- 点击一个节点 → 自动生成闪卡 (正面问题 / 背面答案翻转)
- 点击「测验」→ 弹出自适应题目

**字幕** (逐条弹出):
- 10秒 OCR 识别
- AI 自动建知识图谱
- 一键生成闪卡 + 测验
- 薄弱点一眼看见

**配音**: *"AI 十秒识别，自动建成知识图谱。哪里薄弱、哪里已掌握，一眼看清。还能一键生成闪卡和测验，孩子复习效率翻三倍。"*
**音效**: 轻快的电子节拍 (BPM 120)，每个节点弹出带 "叮" 声

---

### 社交证明/数据锚点 (25–35秒)

**画面**: 仪表盘界面快速闪过
- 统计卡片: "已学 15/50 个知识点"
- 进度条: "30% 完成度"
- 连续学习火焰: "3 天 streak"
- 用量统计: 月卡徽章 + 进度条

**字幕**: 学习进度可视化，家长随时掌握
**配音**: *"学习进度实时可视化，家长打开手机就能看见孩子今天学了什么、哪里还需要补。再也不用追着问'作业写完了吗'。"*
**音效**: 轻快的节拍继续，加入一个温暖的和弦

---

### CTA 行动号召 (35–45秒)

**画面**: 黑底白字大字报风格，或回到真人出镜
**字幕** (大字):
- 评论区扣「学神」
- 免费领取 7 天试用
- 前 50 名送「高考语文古诗文72篇」知识图谱

**配音**: *"评论区扣'学神'，免费领取七天试用。前五十名再送高考语文古诗文七十二篇完整知识图谱。现在就用起来！"*
**音效**: 音乐推向一个小高潮，结尾收束
**贴纸**: 手指指向评论区位置的动画贴纸

## 三、拍摄计划

### 设备
- **首选**: 手机 (iPhone 15 Pro / 华为 Mate 系列 / 小米 14) — 视频号原生竖屏生态，手机拍摄最自然
- **备用**: 三脚架或手机稳定器 (拍摄录屏段落时固定)
- **收音**: 有线耳机麦克风或手机自带 (安静环境下够用)

### 场景
- **真人镜头**: 书房/书桌前，自然光或一盏环形补光灯 (45° 侧光)
- **背景**: 干净书架或白墙，避免杂乱
- **录屏段落**: 在电脑上操作，用 OBS 或手机自带录屏 (竖屏 1080×1920)

### App 状态准备 (录屏前务必检查)
- [ ] 使用 **测试账号** 或 **全新注册账号**，确保无真实用户 PII
- [ ] 知识图谱预置 **高考语文古诗文72篇** 或 **高中数学必修1** 的 demo 数据 (10–15 个节点即可)
- [ ] 仪表盘数据: `totalNodes: 50`, `learnedNodes: 15`, `progressPercentage: 30`, `streakDays: 3`
- [ ] 用量统计: 设置为 **月卡** 状态，上传/测验/对话用量各用 30% 左右 (进度条有颜色变化才好看)
- [ ] 深色模式 vs 浅色模式: **建议用浅色模式** (在视频号信息流中更醒目)
- [ ] 浏览器缩放: 125% 或 150%，确保手机上看清文字
- [ ] 关闭所有通知、弹窗、浏览器插件图标

### 录屏操作流 (精确到秒)

```
00:00 打开 App，停留在登录页 (展示品牌)
00:02 登录进入 Dashboard (展示统计卡片)
00:05 点击 "View Knowledge Graph" 进入图谱页
00:08 展示节点展开动画 (可手动触发或播放已有动画)
00:12 点击一个节点，展示右侧详情面板
00:15 点击 "Generate Flashcards"，展示闪卡翻转
00:18 点击 "Quiz"，展示一道题目和答题
00:22 返回 Dashboard，切换到 Analytics Tab
00:25 展示 Skill Gap 进度条
00:28 展示 Usage Widget (月卡徽章 + 彩色进度条)
00:32 结束录屏
```

### 后期剪辑建议
- **软件**: 剪映专业版 (免费，字幕识别最准)
- **比例**: 9:16 竖屏，1080×1920
- **字幕**: 剪映自动识别 + 手动校对，字体「优设标题黑」或「阿里巴巴普惠体」
- **贴纸**: 在 CTA 段落加 "手指指向" 和 "闪电" 贴纸
- **调色**: 轻微提亮 + 对比度 +5，让录屏文字更清晰
- **BGM**: 剪映内置「轻快/科技/励志」分类，选一首无版权风险的中文电子纯音乐
