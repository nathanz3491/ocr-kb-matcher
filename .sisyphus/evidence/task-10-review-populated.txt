## Expected Runtime Behavior

After a successful upload job:
1. User uploads a document → job created
2. Job processing matches OCR against knowledge tree
3. `markNodesAsKnownWithMastery` marks matched nodes in progress
4. **NEW**: `initializeReview` creates review entries in `data/reviews-{userId}.json`
5. `GET /api/reviews/due` returns those nodes for SM-2 spaced repetition

File created: `data/reviews-{userId}.json` per user (or `reviews.json` if no userId)
Each entry: `{ nodeId, lastReviewed, nextReviewDate, reviewCount: 0, interval: 0, easeFactor: 2.5 }`
